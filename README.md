# 🛒 Amazon Clone (HTML + CSS)
A clean and responsive Amazon homepage clone built using only HTML and CSS.
This project helped me practice layout design, component structuring, and replicating real-world UI patterns from a large-scale website like Amazon.
<br>
<br>
<h2><b>✨ Features</b></h2>

🧭 Fully designed Amazon-style navigation bar
<br>
🎞️ Hero banner/slider layout
<br>
🛍️ Product category boxes (grid-based)
<br>
📦 Reusable card components
<br>
📱 Responsive design for mobile & desktop
<br>
🎨 Pixel-perfect styling similar to Amazon’s UI
<br>
🔥 Hover effects + neat transitions
<br>
<br>
 <h2><b>🛠️ Tech Stack</b></h2>
HTML5
<br>
CSS3 (Flexbox + Grid)

<br>

<br>
